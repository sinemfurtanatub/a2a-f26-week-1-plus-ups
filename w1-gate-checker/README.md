# The Gate checker

Plus-up for the A2A Fall 2026 Week 1 presentation, slide 38 "The Gate: 90+ on three real inputs" (scoring wording from slides 37 and 40).

- `embed.html`: 708x400 (16:9) stage for a Notion embed. Never scrolls.
- `index.html`: the same tool on a full page.

Enter a 0 to 100 score for each of three real inputs (number box or slider). All three at 90 or higher is the green light: save it as a skill. Any score under 90 means stay and tune: the page names which input is under 90 and repeats what slides 37 and 38 say to do. "Start over" clears the scores.

No prompt text is copied here. The Score It 0 to 100 prompt lives on slide 37. No analytics, accounts or network calls. Fonts and logo are embedded. Season Mix is a trial font: confirm the license before publishing publicly.

Status: local build only, not published.
